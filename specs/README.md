# specs/

Spec-driven development artifacts. Added in order, each behind a human gate (SPEC.md §9.4):

| File | Purpose | Gate |
|---|---|---|
| `constitution.md` | Non-negotiable project rules (standards, testing, security) | G2 |
| `plan.md` | Technical plan: architecture decisions, data model, contracts | G2 |
| `tasks.md` | Ordered task list, each task linked to acceptance criteria | G2 |
